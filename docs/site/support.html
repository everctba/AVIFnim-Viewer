Perguntas frequentes

  • É grátis? Sim. O Viewer é gratuito, open source e licenciado sob MIT.
  • Quais formatos abre? AVIF (still e animado), WebP, GIF, PPM/PNM, PNG/JPG e sequências numeradas de PNG/JPG.
  • Não abre uma imagem. Confirme se o arquivo não está corrompido e envie o formato e a versão do Windows no relato.
  • O macOS avisa que o desenvolvedor não pode ser verificado? O app ainda não é assinado/notarizado. Na primeira abertura: botão direito → Abrir → Abrir.
  • Meus arquivos são enviados? Não. Tudo é processado localmente, sem telemetria.

Como reportar um problema

Inclua, se possível:

  • versão do AVIFnim Viewer;
  • versão do Windows;
  • formato do arquivo (AVIF, WebP, GIF, PPM/PNM, PNG/JPG);
  • o que aconteceu e o que você esperava;
  • uma captura de tela, se der.
