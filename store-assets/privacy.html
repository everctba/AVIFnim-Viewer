AVIFnim Viewer

Política de Privacidade

Última atualização: 20 de novembro de 2026

Esta política descreve como o AVIFnim Viewer (“aplicativo”) trata dados. O aplicativo é um visualizador local de imagens, gratuito e open source (MIT).

1. Dados que coletamos

O AVIFnim Viewer não coleta, armazena, transmite nem vende dados pessoais. Não há contas, telemetria, analytics, anúncios ou rastreamento dentro do aplicativo.

2. Arquivos e imagens

As imagens e pastas abertas são processadas localmente no seu dispositivo. Nenhum arquivo é enviado para servidores nossos ou de terceiros.

3. Configurações

Preferências (tema, idioma, zoom, FPS de sequência etc.) são salvas localmente na pasta de dados do aplicativo no Windows (%APPDATA%\com.avifnim.viewer). Elas não são sincronizadas nem enviadas para a nuvem.

4. Rede e links externos

O aplicativo não acessa a internet para funcionar. Quando você clica em links para o site, GitHub ou PayPal, o link é aberto no seu navegador padrão; a partir daí valem as políticas desses sites.

5. Microsoft Store

Se você instalar o aplicativo pela Microsoft Store, a Microsoft poderá coletar dados de uso e diagnóstico conforme a política de privacidade da própria Microsoft Store. Não temos acesso a dados pessoais coletados pela Store.

6. Crianças

O aplicativo não coleta dados pessoais e é adequado para todas as idades.

7. Site

O site do AVIFnim pode usar cookies ou ferramentas de análise para entender visitas e melhorar o conteúdo. O aplicativo AVIFnim Viewer em si não usa esses recursos.

8. Alterações

Se esta política mudar, a versão atualizada será publicada nesta página com nova data.
